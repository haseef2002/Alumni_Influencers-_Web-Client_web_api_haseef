# Alumni Influencer Portal & Analytics Dashboard

A secure, full-stack enterprise application designed to manage alumni engagement and provide deep analytical insights into graduate career trajectories.

## Quick Start & Setup

### Prerequisites
* **Node.js** (v16.x or higher)
* **MySQL** (via XAMPP or separate instance)
* **Git Bash** (recommended for Windows users)
